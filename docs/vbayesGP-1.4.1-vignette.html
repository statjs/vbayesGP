vbayesGP fits Bayesian semiparametric regression models in which a set of exposures enters through a Gaussian process surface, by Gaussian variational approximation. The outcome can be continuous, binary or a count; the exposures can enter through one kernel or through several weighted indices; and cluster-level random intercepts and slopes can be added to every model. The fitting functions are

outcome one kernel several indices
continuous gvagpr() gvagpmim()
binary or count gvaggpr() gvaggpmim()

Everything downstream – summaries, fitted surfaces, predictions, exposure-response curves, overall and single-exposure risks, inclusion probabilities, random effects and the evidence lower bound – works the same way on all four.

This vignette walks through each of them on simulated data. The data sets are small (two hundred observations) and some optimiser runs are capped so that the document builds in a few minutes; drop the control arguments for a real analysis and let the stopping rule decide.

library(vbayesGP)

Simulated data

Four exposures, one covariate, and a surface that depends on the first two exposures only: a quadratic in each, with an interaction. The third and fourth exposures are noise, which is what the inclusion probabilities should find. (A purely linear effect is a long length-scale to the kernel, and the shrinkage prior on the length-scales reads it as weak; the surfaces the package is meant for are the curved ones.)

set.seed(2026)
n <- 200
Z <- matrix(runif(n * 4, -1, 1), n, 4, dimnames = list(NULL, c("As", "Cd", "Pb", "Hg")))
X <- cbind(age = rnorm(n))
h <- 2 * Z[, "As"]^2 - 1.5 * Z[, "Cd"]^2 + Z[, "As"] * Z[, "Cd"]
h <- h - mean(h)
y <- 0.5 * X[, "age"] + h + rnorm(n, sd = 0.5)

Exposure-response summaries

The single-exposure curves hold the other exposures at a quantile (q.fixed), the overall risk compares the surface with every exposure at a quantile against the median, and the single-variable risk asks how much one exposure moves the surface between two of its quantiles while the rest stay fixed. Each has a plot() method.

univ <- predictorResponseUnivar(fit, ngrid = 25, nsamples = 300)
plot(univ)

risk <- computeOverallRisk(fit, qs = seq(0.25, 0.75, by = 0.05), nsamples = 300)
plot(risk)

sv <- computeSingVarRisk(fit, which.z = 1:4, nsamples = 300)

Which exposures matter

The basic models put independent normal priors on the length-scales by default. Under a shrinkage prior instead – "horseshoe" for a continuous outcome, "betaprime" for a binary or count one – computePPIPs() turns the posterior draws of the length-scales into a pseudo posterior inclusion probability per exposure. Here the first two exposures carry the surface and the last two do not. (gvaggpmim() uses the horseshoe by default; gvagpmim() takes it the same way as here.)

fit.hs <- gvagpr(y, X, Z, priors = list(lengthscale = "horseshoe"),
                 minibatch = FALSE, verbose = FALSE, seed = 1)
computePPIPs(fit.hs, nsamples = 500)
#>   variable  PPIP
#> 1       As 0.998
#> 2       Cd 0.834
#> 3       Pb 0.000
#> 4       Hg 0.000

Binary and count outcomes: gvaggpr()

The same model with a logit or log link, fitted through Pólya-Gamma augmentation and an inducing-point approximation to the process. The number of inducing points is control$ninpts (50 by default); the fits below use 30. The binary fit asks for the beta-prime shrinkage prior so that inclusion probabilities are available afterwards; the count fit keeps the default.

A count fit reports c.unconverged, the share of updates at which the inner fixed point of the Pólya-Gamma bound did not reach its tolerance within control$cit passes. On count data it is routinely close to one, because the tolerance sits below what double precision reaches there; it is a report, not a warning, and raising cit does not change the fit.

#> NULL

Random intercepts and slopes

Give id to add a random intercept per cluster, and random.slope (a column index of X) to add a random slope. The variational covariance of the fit is chosen with covstr: "blockdiag" keeps one block per cluster and one for the shared parameters, "sparseprec" uses a sparse precision factor whose cost grows linearly with the number of clusters, and "diagonal" is the mean field. Random-effects fits always use the whole sample.

nID <- 20
id <- rep(seq_len(nID), each = n / nID)
b0 <- rnorm(nID, 0, 0.6)
yr <- rbinom(n, 1, plogis(0.5 * X[, "age"] + h + b0[id]))
## the caps on the optimiser keep the document quick (see the index section)
ctl <- list(ninpts = 30, max_iter = 4000, nws = 500, nsp = 30)
fitr <- gvaggpr(yr, X, Z, id = id, family = binomial(), covstr = "blockdiag",
                control = ctl, verbose = FALSE, seed = 1)
summary(fitr)

extractRandomEffects() returns the variational mean and standard deviation of each cluster’s effects and their covariance Sigma.b; summary() prints the same covariance. With random.slope = 1 the covariance is 2 x 2 and re$mean has a column per effect.

The multiple index model: gvagpmim() and gvaggpmim()

When the exposures form groups – metals, phenols, and so on – each group can enter through a weighted index, and the surface is a function of the index scores. The grouping is given either as a named list of exposure matrices, as below, or as one matrix with m.index, a list of column indices. The fit reports the index weights (alpha., each index normalised to unit length with its last weight positive), the signed coordinates behind them (psi.), the index length-scales (gamma.) and the amplitude (lambda).

set.seed(7)
g1 <- matrix(runif(n * 3, -1, 1), n, 3, dimnames = list(NULL, c("As", "Cd", "Pb")))
g2 <- matrix(runif(n * 2, -1, 1), n, 2, dimnames = list(NULL, c("p1", "p2")))
g3 <- matrix(runif(n * 1, -1, 1), n, 1, dimnames = list(NULL, "s1"))
Zm <- list(metals = g1, phenols = g2, single = g3)
s1 <- as.numeric(g1 %*% c(0.8, 0.6, 0))        # Pb carries no weight
s2 <- as.numeric(g2 %*% c(0.7, 0.7))           # the third index carries nothing
hm <- (2 * s1 + 0.5)^2 - (2 * s2)^2
hm <- hm - mean(hm)
ym <- 0.5 * X[, "age"] + hm + rnorm(n, sd = 0.5)
fitm <- gvagpmim(ym, X, Zm, priors = list(lengthscale = "horseshoe"),
                 minibatch = FALSE, verbose = FALSE, seed = 1)

Mini-batches

minibatch = TRUE (the default) fits the fixed-effects models by stochastic optimisation on batches of the data, which caps the cost of an update as n grows. The split is control$batch.size for the continuous and count models; a binary index model fixes it at 150 and asks for at least five hundred observations, below which it warns and should be given minibatch = FALSE as above. Random-effects fits ignore minibatch. The posterior summaries are the same whichever way the fit was made.

Settings, reproducibility and diagnostics

  • seed fixes the variational fit exactly: two calls with the same data and seed return the same object to the last digit, on every platform.
  • control carries the optimiser settings: max_iter, the smoothing window nws and the patience nsp of the stopping rule, ninpts and cit for the Pólya-Gamma fits. plot(fit) shows whether the bound had settled.
  • A Pólya-Gamma index fit also reports cond.K_IP, the condition number of its inducing-point kernel at the returned length-scales.
  • If a covariance matrix inside a bound cannot be factorised at some point of the optimisation, the fit stops with an error rather than returning a value; a different seed, fewer exposures or a smaller ninpts usually clears it.
